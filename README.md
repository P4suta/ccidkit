# Ccidkit

Access smart cards through USB CCID, PC/SC, and virtual readers in Rust.

## Installation

```sh
git clone https://github.com/P4suta/ccidkit.git
cd ccidkit
mise trust
mise install
```

## Usage

```sh
mise x -- cargo run --locked -p ccid-cli -- --help
```
